## Phase 8 · 轻量后端（可选，远期）

> 目标：数据 API 化便于管理与扩展，不做用户系统。

- [ ] 数据层抽象：定义 `dataProvider` 接口（getPlayers/getSongs/...），当前实现为静态 import，保持页面代码不变

## 优先级与依赖关系

```
Phase 4 (数据) ──→ Phase 5 (新页面，依赖新数据)
                ──→ Phase 6.2/6.3 (转会/成就，依赖时间属性)
Phase 7.1 (测试) ──→ 建议尽早做，为 Phase 4 数据改动兜底
Phase 7.2-7.4 (性能/CI/部署) ──→ 可随时穿插，建议 Phase 5 完成后集中做
Phase 8 (后端) ──→ 最后，且可选
```
